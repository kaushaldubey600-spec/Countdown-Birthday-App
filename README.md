# Countdown Birthday App 🎂

A beautiful Birthday Countdown App using HTML, CSS and JavaScript.

## Features
- Live Birthday Countdown
- Days, Hours, Minutes and Seconds
- Happy Birthday Message
- Responsive Design
- Set Another Birthday

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project.
2. Open the project folder.
3. Open index.html in your browser.
